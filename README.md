# HomePlate-AI
AI推荐家庭菜谱管理与食材采购助手（完整版）
## 项目简介
本项目是面向家庭用户的移动端完整Web应用，采用前后端分离架构，集成AI智能菜谱推荐、冰箱食材库存管理、智能采购清单自动生成、菜谱收藏、个人中心全业务闭环，适用于软件工程毕业设计完整交付。
视觉设计规范：清新温暖美食风格，主色调暖橙色#FF8C38 + 健康绿色#2E7D32，全局卡片圆角16px，留白充足，移动端底部Tab导航布局。

## 技术栈
### 前端
React + Vite + Tailwind CSS，移动端响应式布局
### 后端
Node.js + Express，提供全套业务接口
### 数据库
MySQL，实现用户、食材、菜谱、采购清单云端持久化存储
### AI能力
对接通用大模型API，根据家中库存、饮食忌口、口味偏好生成个性化推荐菜谱

## 核心功能模块
1. **首页 - AI智能菜谱推荐**
顶部搜索框，AI个性化菜品推荐卡片展示，包含菜品耗时、难度、食材预览
2. **冰箱食材库存管理**
食材新增/编辑/删除、保质期录入、临期食材高亮提醒、家庭多成员共享库存
3. **智能采购清单**
自动比对菜谱所需食材与现有库存，一键生成缺购清单，支持手动修改、勾选完成采购
4. **菜谱详情页**
完整用料清单、分步烹饪教程、烹饪时长、收藏功能、营养成分展示
5. **个人中心**
用户登录注册、个人信息修改、我的收藏菜谱、饮食统计周报、基础系统设置
